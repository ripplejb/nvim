# 💤 LazyVim

## Prerequisites

Dear friend,
Before you begin,
Please ensure you have the following prerequisites installed:

- git
- lazygit
- ripgrep
- fd
- fzf
- nodejs [If you don't want node support, remove the plugins]
- golang [If you don't want golang support, remove the plugins]

**To set up clipboard, please set up appropriate clipboard tool for your OS:**

- Linux with X11: `xclip` or `xsel`
- Linux with Wayland: `wl-clipboard`
- Windows: `win32yank.exe` (included with LazyVim)
- MacOS: No additional tool needed

A starter template for [LazyVim](https://github.com/LazyVim/LazyVim).
Please review the [documentation](https://lazyvim.github.io/installation) to get started.
